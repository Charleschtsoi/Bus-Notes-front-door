# TransitInk widget checklist — 青富苑 frontdoor

Complete on the device portal after first boot.

## A. Join setup Wi-Fi

1. Read SSID `TransitInk-xxxx` + password on the Note 4 screen.
2. On phone/Mac, join that Wi-Fi.
3. Open **http://192.168.4.1/**
4. Enter home **2.4 GHz** Wi-Fi name + password → Save.
5. Device rejoins home Wi-Fi. Press **Volume Up** for LAN portal (IP / QR).

## B. Page 1 — Weekday (keep this page for weekday mornings)

Add 4× **KMB / LWB 巴士** widgets:

1. **49M** → stop **青富苑** → toward **青衣站**
2. **A32** → stop **長青邨青桃樓** → toward **機場**
3. **948B** → stop **青富苑** → toward **天后**
4. **948A** → stop **長青邨青桃樓** → toward **天后**

## C. Page 2 — Overflow + weekend

1. **948** → **長青邨青桃樓** → **天后**
2. **X42C** → **青富苑** (if missing early trips, use **長青邨青桃樓**) → **油塘**
3. **42A** → **長青邨青桃樓** → **西九龍 / 高鐵**
4. **249X** → **長青邨青桃樓** → **博康** (from 青衣站 direction)

## D. Power / refresh

In 設定:

- Daily awake window: **06:00 – 09:30** (enable)
- Confirm HK bus refresh ~60s while awake
- Optional second window for evening if you want

## E. Keys

- **Volume Down** — switch Page 1 ↔ Page 2
- **Wake (big button)** — update outside awake window
